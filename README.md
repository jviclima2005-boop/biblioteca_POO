# Biblioteca POO

<h1>Projeto Biblioteca POO</h1>

<p>Projeto acadêmico desenvolvido em Java com o objetivo de aplicar os conceitos de Programação Orientada a Objetos (POO), utilizando como exemplo diferentes tipos de bibliotecas.</p>

<h2>Estrutura do projeto</h2>

<p>A estrutura proposta utiliza uma classe principal e três subclasses especializadas:</p>

<ul>
  <li><strong>Biblioteca.java:</strong> classe principal, responsável por representar uma biblioteca de forma geral e servir como base para as demais classes.</li>
  <li><strong>BibliotecaPublica.java:</strong> representa bibliotecas públicas, voltadas ao acesso da população.</li>
  <li><strong>BibliotecaUniversitaria.java:</strong> representa bibliotecas vinculadas a instituições de ensino superior, com foco no ambiente acadêmico.</li>
  <li><strong>BibliotecaDigital.java:</strong> representa bibliotecas que disponibilizam livros e outros materiais em formato digital.</li>
</ul>

<h2>Conceitos de Programação Orientada a Objetos</h2>

<ul>
  <li><strong>Abstração:</strong> representação de bibliotecas e suas características no código.</li>
  <li><strong>Encapsulamento:</strong> proteção e controle de acesso aos atributos e métodos.</li>
  <li><strong>Herança:</strong> compartilhamento de características da classe Biblioteca com suas subclasses.</li>
  <li><strong>Polimorfismo:</strong> possibilidade de especializar comportamentos de acordo com cada tipo de biblioteca.</li>
</ul>

<h2>Tecnologias utilizadas</h2>

<ul>
  <li>Java</li>
  <li>Programação Orientada a Objetos (POO)</li>
  <li>Visual Studio Code</li>
  <li>Git e GitHub</li>
</ul>

<h2>Objetivo</h2>

<p>Consolidar os conhecimentos de Programação Orientada a Objetos por meio da construção de um sistema que representa diferentes modelos de bibliotecas.</p>

<p><em>Projeto desenvolvido para fins acadêmicos.</em></p>
